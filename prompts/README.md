# Prompt Archive

Save the actual user prompts used for each implementation iteration here (one Markdown file per iteration, such as `iteration-01.md`). Preserve the user wording; do not reconstruct or embellish it later. The matching `docs/iterations.md` entry can summarize scope and acceptance checks and link to the archived prompt.

Do not put credentials, private account data, or unrelated personal information in this archive. Do not write the submitter's reflection for them.
